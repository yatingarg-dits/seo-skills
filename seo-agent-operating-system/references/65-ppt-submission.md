# PPT Submission

## Source activity

Publish useful presentation content on approved presentation/document-sharing platforms and include a relevant website reference when permitted.

## Purpose

Distribute presentation-format expertise, increase brand visibility, create referral paths, and potentially earn a platform link.

## Prerequisites

Require approved presentation, client/property branding, topic/title, description, target URL, and approved sharing platform/account.

## Process

1. Select a presentation topic relevant to the business and audience.
2. Use an existing approved deck or create a presentation through the team's content process.
3. Remove confidential/internal-only information.
4. Add brand identity and source attribution where needed.
5. Include the approved target URL naturally in the deck when useful.
6. Choose an approved presentation-sharing platform.
7. Complete title, description, category, tags, and author/profile fields.
8. Upload the file.
9. Preview slides for broken formatting.
10. Publish.
11. Verify the public presentation URL and any website link.
12. Record status for later monitoring.

## Quality checks

Slides must provide standalone value, links must be relevant and not excessive, confidential data must be removed, rendering must be correct, and platform terms must allow the submission.

## Handoff

If a live backlink exists, use [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md).

## Output record

Store platform, public presentation URL, file/version, target URL, link type/status, publish date, and failure reason.
