# SERP and Competitor Analysis

## Purpose

Validate organic keyword intent and real search competition using current SERP evidence, not only tool difficulty scores.

## Input

Use candidates from [11-organic-keyword-research.md](11-organic-keyword-research.md).

## SERP review

For priority keywords, inspect pages 1-5 where practical and record:

- Ranking URL
- Domain
- Position
- Result type
- Page type
- Title approach
- Search intent served
- Brand versus niche site
- Freshness where relevant
- Major SERP features
- Local pack presence
- Video/image/PAA presence
- Obvious specialist versus broad-site pattern

## Page-type classification

Classify dominant result types:

- Homepage
- Service page
- Product/category page
- Blog/article
- Comparison/listicle
- Forum/community
- Video
- Local page
- Other

## Intent validation

Assign:

- Informational
- Commercial investigation
- Transactional
- Navigational
- Local
- Mixed

If the wording suggests one intent but the SERP shows another, trust the observed SERP and note the discrepancy.

## Allintitle support check

When the team uses `allintitle:` for important terms, record:

- Approximate result count
- Exact/close keyword usage among ranking titles
- Observed title competition

Treat this as supporting evidence only, never as a single approval/rejection rule.

## Competitor gap

For relevant competitors capture:

- Keyword they rank for
- Their ranking URL
- Their position
- Our position if any
- Our URL if any
- Page type difference
- Apparent content gap
- Apparent authority/backlink gap when data exists

## Output

For each keyword return:

- Validated intent
- Dominant page type
- SERP difficulty observations
- Relevant competitor URLs
- Opportunity notes
- Reject/continue decision

Route approved terms to [14-keyword-clustering-mapping.md](14-keyword-clustering-mapping.md).
