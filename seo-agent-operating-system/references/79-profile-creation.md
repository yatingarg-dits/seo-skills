# Profile Creation

## Source activity

Create accurate business/professional profiles on approved social, community, directory, or niche platforms and include the website URL when permitted.

## Purpose

Build consistent online presence, brand/entity visibility, referral paths, and legitimate profile links.

## Prerequisites

Require approved business/person identity, name, bio/description, website, logo/photo, location/contact data when needed, social links, and credential ownership process.

## Process

1. Identify a platform relevant to the business, professional identity, niche, or audience.
2. Check for an existing profile before creating a new one.
3. Qualify the platform if the profile is primarily being considered for a backlink.
4. Create/claim the account using approved identity/contact data.
5. Complete the profile accurately and consistently.
6. Add the canonical website URL where permitted.
7. Select appropriate category/skills/industry fields.
8. Add approved image/logo.
9. Complete platform verification.
10. Verify the public profile and website link.
11. Store credential reference and public URL.
12. Maintain profile data when the business changes.

## Stop/review conditions

Stop if duplicate account exists, identity cannot be legitimately verified, platform is irrelevant/spammy, or required data is missing.

## Output record

Store platform, profile URL, account owner/reference, website URL, verification status, created/updated date, backlink status, and duplicate/failure reason.
