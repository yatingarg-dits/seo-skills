# Web 2.0 Submission

## Source activity

Create and maintain content on approved third-party hosted blog/site platforms that may link back to the main website.

## Purpose

Use third-party publishing properties only when they provide legitimate content/audience value. Do not create thin networks or mass properties solely to manufacture links.

## Prerequisites

Require approved platform, property/account ownership rule, topic purpose, client identity/brand guidance, target URL/anchor plan, and content plan.

Use [32-backlink-qualification.md](32-backlink-qualification.md) for external platform quality and [34-backlink-target-anchor.md](34-backlink-target-anchor.md) for link planning.

## Process

1. Choose a legitimate hosted publishing platform relevant to the planned content.
2. Confirm whether a new property is actually needed; avoid duplicate abandoned properties.
3. Create the account/property using approved identity data.
4. Complete profile/about details accurately.
5. Establish a clear topical purpose.
6. Create original, useful content rather than copied/spun content.
7. Add a relevant client link only where it naturally supports the content and platform rules allow it.
8. Publish.
9. Verify page, link, canonical/indexability behavior where relevant.
10. Maintain the property if the strategy expects ongoing use.

## Stop/reject conditions

Reject when platform is spammy/unsafe, property would be a thin link shell, scaling requires copied/spun content, account creation violates terms, or ownership/maintenance rule is missing.

## Output record

Store platform, property URL, account reference, content URL, target URL, anchor category, publish date, live/link status, and maintenance owner.
