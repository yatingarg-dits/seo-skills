# Forums

## Source activity

Use relevant online forums to contribute useful information and, where permitted and genuinely relevant, reference a client resource.

## Purpose

Build expertise/reputation and targeted referral visibility. Do not use forums for mass signature-link or comment spam.

## Prerequisites

Require relevant active forum, approved account/identity, community rules reviewed, topic/thread relevance, and client resource only if directly useful.

## Process

1. Find forums relevant to the client's niche/audience.
2. Review activity level, moderation, community quality, and promotion/link rules.
3. Search for existing account/profile and duplicate participation.
4. Create/complete an account only when legitimate and approved.
5. Read the full thread before replying.
6. Provide a useful standalone contribution.
7. Add a client link only where allowed and directly supportive.
8. Avoid repetitive exact-match anchors/signatures.
9. Publish.
10. Monitor moderation/replies when this workflow owns ongoing engagement.
11. Record live thread/reply/profile URL and link status.

## Stop/reject conditions

Reject if forum is inactive/spam-dominated, thread is irrelevant, community disallows the intended promotion, or account would be created only to drop a link.

## Output record

Store forum, account, thread, reply URL, topic, target URL, publish date, moderation status, and backlink/referral status.
