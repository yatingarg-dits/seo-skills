# Blog Directory Submission

## Source activity

Submit an eligible client blog to relevant blog-directory platforms.

## Purpose

Increase blog discovery, referral visibility, and potential directory links where the directory is legitimate and useful.

## Prerequisites

Require active client blog, canonical blog/home URL, blog title, description, category/topic, contact/profile information when required, and qualified directory.

Use [32-backlink-qualification.md](32-backlink-qualification.md) for external directory quality when the directory provides links.

## Process

1. Find a relevant active blog directory.
2. Check directory legitimacy, niche/category coverage, and whether submissions are accepted.
3. Search for an existing listing to avoid duplicates.
4. Confirm free/paid/verification requirements.
5. Prepare approved blog title, URL, description, category, feed URL if required, and contact details.
6. Submit the listing.
7. Complete email/site verification if required.
8. Verify the public listing after approval.
9. Verify website/blog link.
10. Store directory listing URL and status.

## Stop/reject conditions

Reject when directory is inactive/spammy, category is irrelevant, duplicate exists, paid listing lacks approval, or reciprocal/manipulative linking is required without approval.

## Output record

Store directory, submission URL, public listing URL, blog URL, category, free/paid, verification status, date, backlink status, and rejection reason.
