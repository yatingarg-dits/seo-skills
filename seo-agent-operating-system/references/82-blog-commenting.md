# Blog Commenting

## Source activity

Leave meaningful comments on relevant blog posts and include a website reference only where the blog permits it and the reference is appropriate.

## Purpose

Build relationships, visibility, discussion participation, and referral opportunities. Do not use automated or generic comments for link volume.

## Prerequisites

Require relevant blog post, legitimate commenter identity, understanding of the article, platform/comment policy, and client link only when appropriate.

## Process

1. Find a relevant high-quality article/blog discussion.
2. Read the full post and existing comments.
3. Decide whether the team has a genuine point, question, example, or useful addition.
4. Draft a specific comment that demonstrates the article was read.
5. Use real/approved identity details.
6. Add a website URL only in the designated field or content where allowed and genuinely relevant.
7. Submit.
8. Record moderation/pending status.
9. Verify the live comment if approved.
10. Track referral/link status only when meaningful.

## Reject examples

Do not post generic praise, repetitive template comments, keyword-stuffed names, irrelevant promotional links, or automated bulk comments.

## Output record

Store blog/domain, article URL, commenter identity reference, comment text/reference, target URL if used, submission date, approval/live status, and removal/rejection reason.
