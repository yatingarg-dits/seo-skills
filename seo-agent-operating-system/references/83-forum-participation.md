# Forum Participation

## Source activity

Participate consistently in relevant forum discussions to build credibility and provide useful expertise, with links used only where contextually appropriate.

## Relationship to Forums

The supplied activity document describes Forum Participation and Forums with substantially overlapping meaning. Use [81-forums.md](81-forums.md) for the core forum execution rules. This file emphasizes ongoing participation rather than a single thread/reply.

## Purpose

Build a credible long-term community presence, learn audience questions, and drive qualified referral traffic without link-first behavior.

## Process

1. Select an approved relevant forum/community.
2. Review community rules, moderator expectations, and promotion limits.
3. Establish an accurate profile using approved identity data.
4. Identify recurring topics/questions relevant to the client's expertise.
5. Participate in discussions without requiring a backlink in every interaction.
6. Answer questions and share examples/resources when genuinely helpful.
7. Use a client link only when it improves the answer and is allowed.
8. Track moderation signals, warnings, and removed posts.
9. Build a participation history before high-promotional activity.
10. Periodically review whether the forum still has relevant audience/activity.

## Guardrails

Do not automate mass replies, resurrect old threads only to place links, disguise commercial affiliation when disclosure is required, or create multiple deceptive identities.

## Output record

Store forum, profile URL, participation period, key threads/replies, target URLs used, moderation status, referral/link outcomes, and notes.
