# Guest Blogging

## Source activity

Contribute blog content to an external website in exchange for exposure and, where permitted, a relevant backlink.

## Relationship to Guest Posting

The supplied activity document describes Guest Blogging and Guest Posting with substantially overlapping steps. Treat this as a source-defined separate activity label, but reuse the same qualification and editorial controls as [69-guest-posting.md](69-guest-posting.md) unless the team supplies a distinct rule.

## Purpose

Support external editorial contribution, brand authority, audience reach, referral traffic, and qualified backlinks.

## Process

1. Qualify the target blog/site using [32-backlink-qualification.md](32-backlink-qualification.md).
2. Confirm the blog accepts external contributors.
3. Review audience, topics, recent posts, editorial standards, author policy, and link policy.
4. Propose a relevant topic not already over-covered.
5. Pitch using the approved outreach route.
6. Agree on topic, format, word range, author bio, link rules, commercial terms, and deadline.
7. Create original content using [35-backlink-content-generation.md](35-backlink-content-generation.md). When the requested asset matches the approved guest-article format, load [90-prompt-library-index.md](90-prompt-library-index.md) and the exact [101-prompt-guest-article.md](101-prompt-guest-article.md) prompt.
8. Apply [36-publisher-guidelines.md](36-publisher-guidelines.md).
9. Submit through [37-backlink-outreach-submission.md](37-backlink-outreach-submission.md).
10. Review edits/approval.
11. Verify live publication and backlink through [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md).

## Stop/review conditions

Use the same stop/review logic as Guest Posting. Do not create a different threshold merely because the label is Guest Blogging.

## Output record

Store publisher, topic, pitch/submission dates, content reference, author, target URL, anchor, live URL, commercial status, and outcome.
