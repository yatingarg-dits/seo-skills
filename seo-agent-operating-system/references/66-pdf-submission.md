# PDF Submission

## Source activity

Publish approved PDFs such as guides, whitepapers, eBooks, checklists, or reports on relevant document-sharing platforms.

## Purpose

Use [07-seo-content-tool-stack.md](07-seo-content-tool-stack.md) for Canva or other approved document/visual production tools; the PDF must still pass content/source validation.

Increase document visibility, referral opportunities, branded content distribution, and potential link exposure.

## Prerequisites

Require final approved PDF, rights to distribute it, client/property branding, target URL(s), and approved platform/account.

## Process

1. Choose a useful document that supports a business/topic objective.
2. Review the PDF for outdated or confidential information.
3. Confirm website URLs inside the PDF are correct and relevant.
4. Ensure title, author/brand, metadata, and contact references are approved.
5. Select a legitimate document-sharing platform.
6. Check platform file-size, category, tagging, and link rules.
7. Upload the PDF.
8. Add a unique, accurate platform description.
9. Publish.
10. Open the public document page and verify rendering/download/access.
11. Verify any external website link.
12. Record the live URL and status.

## Quality checks

PDF must provide useful content, branding and links must be current, sensitive information must not be exposed, and the platform must be legitimate and relevant.

## Handoff

If a live backlink exists, use [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md).

## Output record

Store platform, document title, public URL, file/version, target URL, link status, publish date, and monitoring status.
