# Backlinks

## Source activity

Create or acquire individual external links pointing to approved client pages.

## Purpose

Use this file for link-level execution and recording after strategy, discovery, and qualification are complete.

## Prerequisites

Require qualified source from [32-backlink-qualification.md](32-backlink-qualification.md), activity type from [33-backlink-activity-classification.md](33-backlink-activity-classification.md), target/anchor plan from [34-backlink-target-anchor.md](34-backlink-target-anchor.md), and activity-specific file from [59-offpage-activity-map.md](59-offpage-activity-map.md).

## Process

1. Confirm the external website/platform is still valid.
2. Confirm the client does not already have the same unnecessary placement.
3. Confirm target URL is live/indexable and relevant.
4. Confirm anchor/link format for the activity.
5. Execute through the activity-specific workflow.
6. Record commercial/access status.
7. Capture the live URL after publication.
8. Verify target, anchor, link attribute, placement, and page status through [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md).
9. Capture outcome and rejection reason through [39-backlink-feedback-learning.md](39-backlink-feedback-learning.md).

## Backlink record fields

Store source domain, source page URL, discovery source, activity type, niche/geography, qualification result, client target URL, anchor text/category, link attribute when observable, commercial status, submitted/live/last-checked dates, live/lost status, indexing status when monitored, and notes/rejection reason.

## Decision rule

Do not evaluate a backlink from a single metric. Use relevance, audience, real visibility, site quality, risk, placement, and business fit together.
