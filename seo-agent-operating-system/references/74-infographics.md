# Infographics

## Source activity

Create and distribute informative visual assets that can earn shares, referral traffic, mentions, and backlinks.

## Purpose

Use [07-seo-content-tool-stack.md](07-seo-content-tool-stack.md) for Canva or other approved visual-production tools; verify every statistic/source before design/export.

Use visual data/storytelling as a linkable and shareable asset rather than submitting the same graphic indiscriminately everywhere.

## Prerequisites

Require approved topic/data/source, final infographic asset, source/client landing page, brand attribution, and distribution/outreach targets.

## Process

1. Choose a topic that benefits from visual explanation.
2. Validate all data, statistics, labels, and sources.
3. Design the infographic using approved branding.
4. Publish the primary asset on an appropriate client page when part of the strategy.
5. Prepare embed/share instructions only if approved.
6. Identify relevant visual-sharing platforms, publishers, bloggers, communities, and journalists.
7. Qualify external sites before outreach/submission.
8. Submit or pitch the visual with a tailored description.
9. Ask for/source attribution naturally; do not demand manipulative anchor text.
10. Verify live shares/mentions/backlinks.
11. Record reuse and attribution status.

## Stop/review conditions

Stop if data cannot be verified, asset rights are unclear, platform requires unsupported claims, or distribution target is irrelevant/spammy.

## Handoff

Use [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md) for earned/placed links.

## Output record

Store asset, client source page, target platform/publisher, submission/pitch date, live URL, attribution/link status, and tracked performance/coverage.
