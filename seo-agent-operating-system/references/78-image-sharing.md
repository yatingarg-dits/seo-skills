# Image Sharing

## Source activity

Share approved business/topic images on relevant image or visual-discovery platforms.

## Purpose

Increase visual brand discovery, referral traffic, engagement, and potential source attribution.

## Prerequisites

Require rights-approved image, caption/title, alt/accessibility text when supported, target URL if relevant, approved account/platform, and brand attribution rules.

## Process

1. Choose an image relevant to the client audience and campaign/topic.
2. Confirm usage rights and privacy/consent where people are depicted.
3. Prepare descriptive title/caption.
4. Add accurate alt/accessibility text when the platform supports it.
5. Add approved tags/categories/boards/albums.
6. Add a relevant website link where the platform allows and where it provides user value.
7. Publish.
8. Verify the public image/post page.
9. Verify the target link if present.
10. Record engagement/referral data when part of KPIs.

## Stop/review conditions

Stop when rights/consent are unclear, image contains confidential/personal information not approved for publishing, platform is irrelevant/spammy, or link would be misleading.

## Output record

Store platform, image/post URL, asset reference, caption, target URL, publish date, backlink status, and tracked performance metrics.
