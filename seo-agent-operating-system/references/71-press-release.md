# Press Release

## Source activity

Distribute a genuinely newsworthy business announcement through approved press-release services or media outreach.

## Purpose

Build awareness, media discovery, referral traffic, and potential editorial mentions. Do not create press releases solely to manufacture followed backlinks.

## Prerequisites

Require newsworthy event/update, approved facts/dates/quotes/names/company description, media contact, target audience/geography, and approved release/distribution channel.

## Process

1. Confirm the announcement is actually newsworthy.
2. Gather verified facts and approved spokesperson quote if used.
3. Draft headline, summary, body, company boilerplate, and media contact.
4. Add relevant website references without keyword-stuffed anchor tactics.
5. Complete legal/brand approval when required.
6. Choose a suitable distribution service or direct media list.
7. Configure geography/category/industry targeting.
8. Submit/publish.
9. Verify the public release URL.
10. Track earned media pickups separately from syndicated copies.
11. Record referral traffic/mentions/backlinks when monitored.

## Stop/review conditions

Stop when announcement lacks factual support, quote/claim lacks approval, distribution requires unapproved payment, or the release exists only for manipulative link volume.

## Output record

Store release title, event, distribution channel, publish date, release URL, target URL, pickup/coverage records, link status, and outcome.
