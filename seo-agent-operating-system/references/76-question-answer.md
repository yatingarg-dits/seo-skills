# Question and Answer (Q&A)

## Source activity

Answer relevant questions on approved Q&A/community platforms and reference a client resource only when it genuinely helps the answer.

## Purpose

Demonstrate expertise, build brand visibility, and drive qualified referral traffic. Do not post link-first or repetitive promotional answers.

## Prerequisites

Require approved platform/account, relevant question, verified subject knowledge/source material, and a client resource that directly supports the answer when a link is used.

## Process

1. Search for questions relevant to the client's expertise and target audience.
2. Check whether the question is active, legitimate, and within account/platform rules.
3. Read existing answers to avoid repeating low-value content.
4. Draft a complete standalone answer first.
5. Use client facts/resources only when accurate and relevant.
6. Add a website link only when it adds evidence, detail, or a useful next step.
7. Disclose affiliation when platform rules or context require it.
8. Publish.
9. Monitor moderation/removal/replies if this activity is owned by the team.
10. Record the live answer URL and referral/link status.

## Stop/reject conditions

Reject if the question is unrelated, answer would be promotional without informational value, platform forbids the intended promotion, or an accurate answer cannot be supported.

## Output record

Store platform, question URL, answer URL, topic, target URL, publish date, moderation status, backlink status, and notes.
