# Backlink Activity Classification

## Purpose

Identify the correct activity for an approved website because different opportunity types require different instructions, content, access, and execution.

## Input

Use qualified candidates from [32-backlink-qualification.md](32-backlink-qualification.md).

## Classify opportunity type

Use the closest approved type, such as:

- Guest post
- Editorial article/contributor post
- Niche edit/link insertion
- Resource page
- Profile
- Forum/community contribution
- Q&A contribution
- Web 2.0/property
- Social/community profile
- Directory/citation-like opportunity
- Outreach-only publisher
- Link exchange/collaboration
- Other approved type

Do not classify business listings here. Route business listings to [40-business-listing-discovery.md](40-business-listing-discovery.md).

## Determine execution mode

Record:

- Self-publish
- Existing contributor account
- New registration
- Submission form
- Email outreach
- Contact-form outreach
- Editor relationship
- Paid mediator
- Collaboration/exchange
- Unknown/manual review

## Determine commercial status

Use:

- FREE
- PAID
- EXCHANGE
- RELATIONSHIP
- UNKNOWN

## Content requirement

Classify:

- Full new article required
- Short description required
- Profile copy required
- Existing content/link insertion
- Comment/community answer
- No content required
- Publisher supplies content

## Site-specific rules

If the site has unique editorial requirements, require [36-publisher-guidelines.md](36-publisher-guidelines.md) before content generation/submission.

## Output

Return:

- Domain/URL
- Opportunity type
- Execution mode
- Commercial status
- Content requirement
- Login/account requirement
- Outreach requirement
- Publisher-guideline status
- Next step

## Handoff

Use:

- [34-backlink-target-anchor.md](34-backlink-target-anchor.md) for target/anchor planning
- [35-backlink-content-generation.md](35-backlink-content-generation.md) when content is needed
- [37-backlink-outreach-submission.md](37-backlink-outreach-submission.md) for execution
