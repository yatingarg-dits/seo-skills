# Organic Keyword Research

## Purpose

Build an organic keyword universe using multiple approved sources and preserve source-specific metrics.

## Prerequisites

Load:

- [10-keyword-intake.md](10-keyword-intake.md)
- [01-platform-seo-context.md](01-platform-seo-context.md)
- [04-property-context.md](04-property-context.md)

## Research sources

Use approved sources available to the team, such as:

- Google Search Console
- Existing ranking data
- Google autocomplete
- Related searches
- People Also Ask
- Google Trends
- Google SERPs
- Google Keyword Planner for demand support
- Competitor websites
- Approved SEO platforms
- Relevant forums/communities when useful

Do not rely on one tool when multiple sources are available.

## Collect per keyword

Store:

- Keyword
- Normalized keyword
- Seed/source
- Topic
- Geography
- Language
- Search volume
- Search volume source
- Organic difficulty
- Difficulty source
- CPC as supporting commercial signal
- Trend/seasonality when available
- Existing rank
- Existing ranking URL
- Existing clicks/impressions/CTR when available
- Business relevance
- Initial intent hypothesis

## Existing-site opportunity scan

Flag:

- Positions 1-3
- Positions 4-10
- Positions 11-20
- Positions 21-50
- High-impression/low-CTR queries
- High-impression queries near page one
- Improving queries
- Declining queries
- Wrong URL ranking
- Multiple URLs for same query
- Non-branded opportunities
- Branded queries

## Guardrails

- Do not choose keywords on search volume alone.
- Do not treat tool KD as an absolute Google metric.
- Do not mix PPC competition with organic difficulty.
- Keep source names with every metric.
- Keep zero/low-volume niche terms if business relevance is strong.
- Exclude clearly irrelevant queries but retain a rejection reason.

## Output

Produce a deduplicated candidate keyword dataset and route it to [13-serp-competitor-analysis.md](13-serp-competitor-analysis.md).
