# SEO Content Brief and Layout

## Purpose

If the requested asset matches the approved prompt library, select it through [90-prompt-library-index.md](90-prompt-library-index.md) before finalizing the brief. Record the selected prompt file and any required shared framework files. Use [95-prompt-meta-tags.md](95-prompt-meta-tags.md), [96-prompt-aeo-search-faqs.md](96-prompt-aeo-search-faqs.md), [98-prompt-calls-to-action.md](98-prompt-calls-to-action.md), or [102-prompt-research-based-article-titles.md](102-prompt-research-based-article-titles.md) when those are separate requested outputs.

Use [07-seo-content-tool-stack.md](07-seo-content-tool-stack.md) when selecting research/briefing tools such as live SERP research, Ahrefs/Semrush, BuzzSumo, AnswerThePublic, Frase, or Surfer. Tool outlines never replace the required information architecture.

Turn approved keyword/topic direction, client/property context, SERP observations, and research requirements into an execution-ready content brief and information architecture. Apply [08-google-search-ranking-systems.md](08-google-search-ranking-systems.md) for people-first/original/reliable/intent controls and [09-ai-llm-discovery-visibility.md](09-ai-llm-discovery-visibility.md) when generative-search citation visibility is an objective.

A brief is not a competitor-heading copy. Build the best recommended structure for the intended user and business objective.

## Required brief components

Include where applicable:

- Primary topic - mandatory
- Search intent - mandatory for SEO/search-led content
- Target audience/ICP/geography - mandatory
- Business objective - mandatory
- Funnel/use context - recommended
- Primary keyword - required for keyword-targeted content
- Supporting topics/queries - required where relevant
- SERP observations - mandatory for SEO content
- Recommended content/page type - mandatory
- Suggested H1 - mandatory
- H2/H3 structure - mandatory
- Questions to answer - mandatory
- Evidence/source requirements - mandatory where factual claims are involved
- Internal-link opportunities - required where available
- CTA direction - required for commercial content
- Differentiation/information-gain angle - mandatory
- Existing-content conflicts/cannibalization - must be checked
- Target URL/new-page requirement
- Metadata direction when relevant
- Approved facts/claims and restrictions
- Required terminology
- Tone/voice
- Author/brand identity when relevant

## SERP-derived guidance

Use current SERP evidence to understand:

- Dominant intent/page type
- Common subtopics/questions
- Content formats
- Important omissions/gaps

Do not mechanically reproduce competitor headings or structures.

## Content depth

Specify the depth needed to satisfy the user and business objective. Do not prescribe word count solely because competitors have a certain length.

## Missing context

If a required business fact, claim, audience, or property rule is absent, mark the relevant missing-context status instead of fabricating it.

- BRIEF_NEEDS_EXPERT_REVIEW
