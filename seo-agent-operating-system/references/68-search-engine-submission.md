# Search Engine Submission

## Source activity

Submit or expose website URLs/sitemaps through approved search-engine webmaster tools to support crawling and indexing discovery.

## Purpose

Help search engines discover eligible client-owned pages. Do not treat submission as a guarantee of indexing or ranking.

## Prerequisites

Require verified site/property access where applicable, live URL, crawl/index eligibility, correct canonical, and XML sitemap where relevant.

Use [21-technical-crawl-indexation.md](21-technical-crawl-indexation.md) for technical eligibility and [53-indexing-monitoring.md](53-indexing-monitoring.md) for monitoring.

## Process

1. Verify the correct search-engine/webmaster property.
2. Confirm the URL returns the intended content.
3. Check robots, meta robots, canonical, redirect status, and sitemap inclusion where applicable.
4. For site-level submission, submit/verify the approved XML sitemap.
5. For important individual URLs, use the search engine's supported inspection/submission workflow when available and approved.
6. Record submission date and response.
7. Monitor discovery/indexing separately.
8. Investigate technical/content causes when a URL remains unindexed instead of repeatedly resubmitting without diagnosis.

## Stop/review conditions

Do not submit staging/test URLs, unintended duplicates, non-canonical URLs unless intentionally required, `noindex` pages, error/redirect URLs as final targets, or URLs excluded by property strategy.

## Success criteria

Submission completed and logged; indexing remains a separate outcome.

## Output record

Store search engine/tool, property, URL/sitemap, submission type, date, response, eligibility result, indexing follow-up, and issue reason.
