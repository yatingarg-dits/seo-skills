Meta Tags 

**Writing parameters** 

- **Tone:** Clear, useful, specific, and credible. 

* **Style:** Search-intent-led copy that communicates the page’s value without sounding promotional. 

- **Language:** Natural sentence construction. Avoid repeated words, pipes, unnecessary capitalization, and awkward exact-match phrasing. 

* **Reader experience:** A searcher should know what the page covers and why it is worth opening. 

- **Quality controls:** Match the visible page, retain the correct intent, use the primary keyword naturally, and verify every character count including spaces. 

* **Output format:** Use a table with option, title, title count, description, description count, intent, and rationale. 

Create metadata for: 

**Topic:** [Topic] 

**Primary keyword:** [Keyword] 

**Search intent:** [Intent] 

**Business outcome:** [Outcome] 

**Reader:** [Audience] 

Provide 5 SEO title options of 50 to 60 characters, 3 meta descriptions of 145 to 160 characters, and one 25-word summary. Use the keyword naturally, focus on the user’s expected value, avoid clickbait, and show exact character counts.
