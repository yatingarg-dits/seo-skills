# Link Building

## Source activity

Acquire backlinks from external websites through outreach, guest content, relationships, useful assets, and other approved methods.

## Purpose

Use this as the strategic orchestration file for building new referring-domain opportunities. Do not use it as a substitute for the activity-specific execution files.

## Prerequisites

Load:

- [04-property-context.md](04-property-context.md)
- [15-keyword-validation-output.md](15-keyword-validation-output.md) when target keywords/pages are known
- [30-backlink-discovery.md](30-backlink-discovery.md)
- [32-backlink-qualification.md](32-backlink-qualification.md)

## Process

1. Define the link-building objective: priority page, topic authority, new referring domain, lost-link replacement, brand/referral visibility, or other approved goal.
2. Confirm target geography, niche, audience, and priority pages from property context.
3. Build candidate sources using [30-backlink-discovery.md](30-backlink-discovery.md).
4. Normalize community/shared-sheet inputs using [31-community-link-intake.md](31-community-link-intake.md).
5. Qualify every external website with [32-backlink-qualification.md](32-backlink-qualification.md).
6. Classify the specific activity using [33-backlink-activity-classification.md](33-backlink-activity-classification.md).
7. Route to the correct execution file in [59-offpage-activity-map.md](59-offpage-activity-map.md).
8. Select client target page and anchor through [34-backlink-target-anchor.md](34-backlink-target-anchor.md) when a backlink is part of the activity.
9. Prepare content through [35-backlink-content-generation.md](35-backlink-content-generation.md) when required.
10. Apply publisher-specific rules from [36-publisher-guidelines.md](36-publisher-guidelines.md).
11. Execute through the activity file or [37-backlink-outreach-submission.md](37-backlink-outreach-submission.md).
12. Verify live placement through [38-backlink-verification-monitoring.md](38-backlink-verification-monitoring.md).
13. Feed outcome/rejection reasons to [39-backlink-feedback-learning.md](39-backlink-feedback-learning.md).

## Decision rules

Prefer opportunities with strong topical relevance, real audience/organic visibility where measurable, legitimate editorial/platform quality, natural target-page fit, and useful new referring-domain value.

Do not approve only because DA/PA/DR is high.

## Stop/review conditions

Route to manual review when paid terms require approval, spam/network risk exists, the site is irrelevant, target/anchor is unclear, reciprocal action is required, or approved credentials are unavailable.

## Output record

Store objective, source, domain/opportunity URL, activity type, qualification result, target URL, anchor category, content reference, commercial status, execution status, live URL, verification date, and rejection/failure reason.
