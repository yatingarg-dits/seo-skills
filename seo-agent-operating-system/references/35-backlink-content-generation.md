# Backlink Content Generation

## Purpose

Create proposed content for an approved backlink opportunity using property context, target/anchor planning, and publisher requirements.

The output is proposed content for human review unless the platform explicitly allows automatic publishing.

## Inputs

Load:

- [04-property-context.md](04-property-context.md)
- [33-backlink-activity-classification.md](33-backlink-activity-classification.md)
- [34-backlink-target-anchor.md](34-backlink-target-anchor.md)
- [36-publisher-guidelines.md](36-publisher-guidelines.md) when site-specific rules exist

## Content types

Generate only the type required:

- Guest post
- Contributor article
- Short article/description
- Profile/about text
- Resource description
- Forum/Q&A contribution
- Outreach pitch copy
- Link-insertion suggestion

## Content requirements

Use only supported client facts.

Align with:

- Client audience
- Client positioning
- Topic relevance
- Target page
- Planned anchor
- Publisher tone/format
- Word-count or formatting rule when explicitly provided
- Author/signature context when required

## Guardrails

- Do not invent client claims, awards, statistics, credentials, or case studies.
- Do not force an anchor where it reads unnaturally.
- Do not reuse one generic article across unrelated publishers.
- Do not ignore publisher restrictions.
- Do not assume the generated content must be used unchanged.

## Quality checks

Before output verify:

- Topic fits publisher and client
- Link fits context
- Client facts are supported
- No conflicting property context
- No duplicate/recycled sections when originality is required
- CTA is appropriate for publisher format
- Author/signature information is correct

## Output

Return:

- Proposed title/topic
- Proposed content
- Target URL
- Anchor/placement
- Author/signature if required
- Publisher requirements applied
- Missing information
- Human review status

## Handoff

Send approved content to [37-backlink-outreach-submission.md](37-backlink-outreach-submission.md).

Send content-quality feedback separately to [39-backlink-feedback-learning.md](39-backlink-feedback-learning.md).
