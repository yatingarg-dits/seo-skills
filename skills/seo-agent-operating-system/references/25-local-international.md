# Local and International SEO Audit

## Purpose

Run only the sections applicable to the property. Do not force local or international checks onto unrelated sites.

## Local SEO checks

When the business serves local markets, review:

- Google Business Profile availability/access
- Business name consistency
- Primary/secondary categories
- Address/service area
- Phone
- Website URL
- Opening hours
- Products/services
- Photos
- Reviews/review response process
- Duplicate listings
- Local landing pages
- NAP consistency
- Local citations
- Local structured data where appropriate
- Local pack visibility
- Local competitor patterns

Keep business-listing execution separate in [40-business-listing-discovery.md](40-business-listing-discovery.md) and [41-business-listing-execution.md](41-business-listing-execution.md).

## International SEO checks

When multiple languages/countries exist, review:

- URL structure by country/language
- `hreflang`
- Self-reference
- Reciprocal/return annotations
- Canonical interaction
- Language/country mismatch
- Sitemap implementation
- Duplicate international pages
- Internal links between localized versions
- Geo/language targeting consistency

## Content checks

Validate that localization is real, not only machine-swapped terms, when business context requires localization.

Flag:

- Wrong currency
- Wrong contact details
- Wrong service availability
- Wrong spelling/terminology for market
- Untranslated critical elements

## Output

Return only applicable findings with:

- Market/location
- URL/profile
- Issue
- Evidence
- Recommendation
- Owner

Route audit findings to [27-audit-prioritization-qa.md](27-audit-prioritization-qa.md).
