# Keyword Research Intake

## Purpose

Prepare a validated starting context before organic or paid keyword research.

## Inputs

Require or derive:

- Property/domain
- Business/service scope
- Target geography
- Target language
- Target audience
- Priority services/products
- Existing important pages
- Conversion goals
- Known competitors
- Existing keyword sheets if available
- GSC/analytics data if available
- Paid campaign objective if PPC research is requested

Load [04-property-context.md](04-property-context.md).

## Website extraction

Collect seed concepts from:

- Homepage
- Navigation
- Service/product pages
- Category pages
- Blog/resource topics
- FAQs
- Titles/H1s
- Existing internal search terminology when available

## Business seed inputs

Add:

- Customer terminology
- Sales terminology
- Common questions
- Pain points
- High-priority services
- High-margin services if provided
- New/future services if approved
- Geo modifiers

## Competitor types

Separate:

- Business competitors: sell similar products/services
- SERP competitors: rank for desired queries

Do not treat them as the same list automatically.

## Existing performance intake

Where available capture:

- Query
- Landing page
- Clicks
- Impressions
- CTR
- Average position
- Country
- Device
- Date range

## Output

Produce:

- Approved research scope
- Seed keyword list
- Business competitor list
- Initial SERP competitor candidates
- Existing ranking keyword set
- Geography/language settings
- Missing context fields

## Decision

Route to:

- [11-organic-keyword-research.md](11-organic-keyword-research.md) for organic
- [12-paid-keyword-research.md](12-paid-keyword-research.md) for paid
- Both when the request explicitly covers organic and paid
