# SEO Content Review

## Purpose

Review drafted website content for search intent, property accuracy, usefulness, on-page requirements, and publication readiness.

## Inputs

Use:

- Draft content
- [50-seo-content-brief.md](50-seo-content-brief.md)
- [04-property-context.md](04-property-context.md)

## Review dimensions

### Property accuracy

Check:

- Services/products stated correctly
- Geography correct
- Audience correct
- Claims supported
- Tone aligned
- Restricted statements avoided

### Search intent

Check:

- Content answers the target intent
- Page type is appropriate
- Main question/problem is addressed early enough
- Commercial content has a clear conversion path where appropriate

### Topic coverage

Check:

- Required brief sections covered
- Missing important subtopics
- Repetition/fluff
- Unsupported filler
- Useful examples/evidence where expected

### On-page SEO

Check:

- Title direction
- H1
- Heading structure
- Natural primary/secondary keyword use
- Internal links
- External references when needed
- Image/alt recommendations where relevant
- Meta description draft if required

### Cannibalization

Recheck whether the content duplicates an existing page's intent. If so, route back to [14-keyword-clustering-mapping.md](14-keyword-clustering-mapping.md).

## Review outcome

Use:

- APPROVED
- APPROVED_WITH_MINOR_EDITS
- MAJOR_REVISION
- FACTUAL_CONTEXT_MISSING
- INTENT_MISMATCH
- CANNIBALIZATION_RISK
- REJECTED_WITH_REASON

## Feedback

Record exact changes rather than vague comments such as "make SEO better."

## Handoff

Send approved content to [52-onpage-implementation-publishing.md](52-onpage-implementation-publishing.md).
